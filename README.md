# Rainstorm

[Link to play game on itch.io](https://giragon6.itch.io/rainstorm)

A simple game made in Godot about surviving during a flood. Dodge raindrops and strategically use magma to reduce the flood waters! 

Currently in a very early and scuffed stage. Assets are mostly temporary and gameplay is subject to change.

This is one of the first Godot games I've made to semi-completion, so it's nothing fancy, but I tried to be creative with the mechanics/goal. Future features will include more dynamic magma spawning, character customization, more interactions with the water, and better flight physics!
